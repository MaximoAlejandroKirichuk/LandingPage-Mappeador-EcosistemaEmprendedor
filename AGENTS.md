# Project Guidelines

## Before Editing
- Read the relevant files under src/** before changing code.
- If you touch a section, also read its CSS in src/App.css and any shared styles in src/index.css.
- For copy changes, review src/content/landingContent.ts first.
- For the form, review src/components/InterestForm.tsx and src/services/interest.service.ts.

## UX and Content
- Keep all user-facing copy in Spanish.
- Maintain a clear, persuasive CTA and a modern visual style.

## UI Behavior
- Preserve the reveal animation and parallax hooks unless explicitly asked to remove them.
